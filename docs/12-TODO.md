# AI Coding Guidelines

Sebelum mulai mengerjakan tugas:

1. Baca dokumen ini.
2. Pilih satu tugas aktif.
3. Pastikan tidak bertabrakan dengan pekerjaan lain.
4. Setelah selesai:
    - ubah status,
    - perbarui dokumentasi terkait,
    - tambahkan catatan jika diperlukan.

AI tidak boleh mengerjakan banyak fitur besar sekaligus tanpa persetujuan.

---

# Definition of Done

Sebuah tugas dianggap selesai apabila:

- Fitur telah diimplementasikan.
- Telah diuji.
- Dokumentasi diperbarui.
- Tidak menimbulkan regression.
- Checklist pada dokumen ini telah diperbarui.
